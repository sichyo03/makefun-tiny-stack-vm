A correct tiny stack VM for make.fun's ISA: 32-bit wrapping integers, a 256-value stack, a 64-deep call stack, 256 words of memory, and all ten traps with their own exit codes. `main.ts` runs each program and writes its stdout and exit code.

## Run it

```sh
node main.ts
```
